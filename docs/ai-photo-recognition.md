# Распознавание еды по фотографии

Пользователь выбирает фотографию или делает снимок из формы «Добавить продукты». Браузер уменьшает изображение до 1280 px по длинной стороне и отправляет его только в Edge Function `nutrition-photo-estimate`.

Функция:

- принимает только JPEG, PNG или WebP;
- требует действующую сессию Supabase;
- проверяет `Origin` по `ALLOWED_ORIGINS`;
- отправляет изображение в OpenAI с `store: false`;
- использует `gpt-4o-mini` и строгую JSON-схему;
- не пишет изображение, base64 или содержимое запроса в логи и Storage.

Результат всегда показывается как редактируемый список. Пользователь может исправить название, вес и КБЖУ. Автоматического сохранения нет — запись создаётся только кнопкой «Сохранить приём пищи».

Явно разделимые продукты возвращаются отдельно. Смешанное готовое блюдо остаётся одной строкой, поэтому история сохраняет выбранный пользователем формат.

## Ручная публикация в staging

После merge запустить workflow `Deploy staging Edge Functions` и ввести предусмотренное workflow подтверждение. Workflow публикует `nutrition-photo-estimate` с проверкой JWT. Секреты `OPENAI_API_KEY` и `ALLOWED_ORIGINS` уже используются Edge Functions и не передаются во frontend.
